# Alfalah Center (Southeast) — premium Next.js redesign

Visual redesign of [alfalahcenter.ca](https://alfalahcenter.ca) with **identical content and photos**.  
Emerald/gold brand matching the live site and Alfalah North family. **Not deployed to production.**

See **[SOURCES.md](./SOURCES.md)** for page inventory, image provenance, and gaps.

## Preview

```bash
cd /workspace/alfalah-center-site
npm install
npm run build
npm run dev    # http://0.0.0.0:3010
```

## Stack

Next.js 16 (App Router) · Tailwind CSS 4 · framer-motion · lucide-react
